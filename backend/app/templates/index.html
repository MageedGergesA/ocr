            {% else %}
            لا أبدًا. مستنداتك تمرّ في خط الاستخراج فقط — لا نخزّنها بعد انتهاء الطلب افتراضيًا (في خطّة Lite فما فوق)، ولا تُستخدم أبدًا لإعادة تدريب نماذج Claude أو Gemini المُستضافة. هذا مضمون تعاقديًا عبر سياسة الخصوصية ويمكن توقيع DPA مخصّصة لخطّتَي Business / Enterprise.

            {% if lang == 'en' %}

            ثبّت mostakhles_extract على Odoo 18 أو 19، الصق مفتاح الـ API في الإعدادات، وسيظهر زر «استخرج بمُستخلِص» على نماذج الفاتورة، فاتورة المورّد، الشريك، وعقد HR. ارفع صورة أو PDF فيتم ملء سجل أودو — مع مطابقة الشريك بالرقم الضريبي، ربط البنود، حساب الضرائب. متاح في خطة Lite فما فوق.
            {% endif %}
