API مُستخلِص

محرّك واحد لاستخراج المستندات العربية — مطبوعة أو بخط اليد — عبر REST بسيط. ادمجه في أي نظام بمفتاح واحد.

REST · JSON مصادقة بمفتاح API عربي وإنجليزي وخط يدوي
المحتوى البدء السريع المصادقة النقاط والتكلفة نقاط النهاية استخراج مستند حالة الدفعة المحادثة المقارنة تقدير التكلفة الاستخدام مرجع رموز الأخطاء

البدء السريع

كل الطلبات تُرسَل إلى عنوان القاعدة التالي عبر HTTPS. أثناء التجربة المحلية استبدله بـ http://localhost:8000.

https://api.mostakhles.ai

أرسل أول مستند خلال ثوانٍ — مفتاحك في لوحة التحكم:

# استخراج تلقائي — نتعرّف على نوع المستند ونعيد حقوله
curl https://api.mostakhles.ai/v1/extract \
  -H "x-api-key: YOUR_API_KEY" \
  -F "file=@invoice.pdf" \
  -F "hard=true"

المصادقة

تتطلب كل نقاط النهاية مفتاح API يُرسَل في الترويسة x-api-key. أنشئ مفاتيحك وألغِها في أي وقت من لوحة التحكم.

x-api-key: YOUR_API_KEY
مستنداتك لا تُخزَّن. تُعالَج في الذاكرة وتُحذَف فور انتهاء الطلب — ولا تُستخدم لتدريب النماذج.

النقاط والتكلفة

تُحتسب كل صفحة بالنقاط حسب الوضع. النقاط مشتركة عبر الويب والـ API وأودو.

الوضعالمعاملالتكلفة / صفحةالأنسب لـ
سريعhard=false1 نقطةالمستندات المطبوعة الواضحة
دقيقhard=true (الافتراضي)8 نقاطالعربي والخط اليدوي والمستندات المعقّدة

المقارنة تكلّف ضعف ذلك (مستندان). لا تُحتسب الطلبات الفاشلة، ولا نقطة نهاية /v1/estimate.

POST/v1/extract

استخرج بيانات منظّمة من صورة أو PDF. بدون target_schema نتعرّف تلقائيًا على نوع المستند ونعيد حقوله؛ ومعه نعيد الحقول التي حدّدتها بدقة.

المعاملات (multipart/form-data)

الحقلالنوعالوصف
fileملف مطلوبPNG · JPG · WEBP · GIF · PDF (حتى 20MB)
hardbooleanالوضع الدقيق (الافتراضي true)
target_schemaJSONاختياري: {"اسم_الحقل": "وصفه"} — يُفعّل وضع المخطط المخصص

مثال — مخطط مخصص

curl https://api.mostakhles.ai/v1/extract \
  -H "x-api-key: YOUR_API_KEY" \
  -F "file=@invoice.pdf" \
  -F 'target_schema={"invoice_no":"رقم الفاتورة","total":"الإجمالي"}'

الاستجابة 200

{
  "mode": "auto",
  "document_type": "invoice",
  "data": {
    "invoice_no": "INV-2025-0042",
    "total": "1,530"
  },
  "usage": { "used": 48, "limit": 1500, "remaining": 1452, "charged": 8 }
}
الملفات الكبيرة تتحوّل إلى دفعة. أي PDF بأكثر من 5 صفحات يُعالَج في الخلفية صفحةً صفحةً، فتعيد الاستجابة {"mode":"batch","job_id":"…","total_pages":N} — تابع تقدّمها عبر /v1/jobs/{id}.
GET/v1/jobs/{job_id}

تابع تقدّم دفعة ونتائجها الجزئية.

curl https://api.mostakhles.ai/v1/jobs/JOB_ID \
  -H "x-api-key: YOUR_API_KEY"
{ "job_id": "…", "status": "processing", "done": 12, "total_pages": 30, "results": [ … ] }
POST/v1/chat 1 نقطة

اطرح سؤالًا على نص مستند مستخرَج: «ما الإجمالي؟»، «من وقّع؟»، «لخّص العقد».

curl https://api.mostakhles.ai/v1/chat \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text":"نص المستند…","question":"ما إجمالي الفاتورة؟","history":[]}'
{ "answer": "إجمالي الفاتورة 1,530 ج.م.", "usage": { "charged": 1, … } }
POST/v1/compare مستندان

قارن مستندين واكتشف ما تغيّر وما الناقص وما المتطابق.

curl https://api.mostakhles.ai/v1/compare \
  -H "x-api-key: YOUR_API_KEY" \
  -F "file_a=@v1.pdf" -F "file_b=@v2.pdf" -F "hard=true"
{ "report": "الفروقات: تغيّرت قيمة العقد من … إلى …", "usage": { … } }
POST/v1/estimate مجاني

قدّر التكلفة قبل التنفيذ: عدد الصفحات والنقاط في الوضعين ورصيدك الحالي. لا يستهلك نقاطًا.

curl https://api.mostakhles.ai/v1/estimate \
  -H "x-api-key: YOUR_API_KEY" -F "file=@doc.pdf"
{ "pages": 3, "cost_strong": 24, "cost_fast": 3, "remaining": 1452, "limit": 1500 }
GET/v1/usage مجاني

اعرض خطتك واستهلاكك الشهري ورصيدك المتبقّي.

curl https://api.mostakhles.ai/v1/usage -H "x-api-key: YOUR_API_KEY"
{ "plan": "starter", "used": 48, "limit": 1500, "remaining": 1452 }

رموز الأخطاء

تعيد الواجهة رموز HTTP قياسية مع رسالة في الحقل detail.

الرمزالمعنى
400طلب غير صالح — مثل target_schema ليس JSON صحيحًا، أو حقول ناقصة
401مفتاح API مفقود أو غير صالح أو مُلغى
413الملف أكبر من 20MB، أو عدد صفحات الـ PDF يتجاوز الحد
415نوع ملف غير مدعوم — استخدم PNG/JPG/WEBP/GIF/PDF
429تجاوزت حصتك الشهرية — رقِّ خطتك أو انتظر الشهر التالي
502فشل الاستخراج من النموذج (لا تُحتسب نقاط)
