Mostakhles — Arabic Document AI for Odoo

Extract structured fields from Arabic invoices, national IDs, prescriptions, contracts, and handwritten documents — straight into Odoo records, in one click.

Why Mostakhles?

Generic OCR fails on Arabic. Google Vision, AWS Textract, and Mindee were trained on Western printed text — they struggle with cursive Arabic, mixed Arabic-English documents, handwritten prescriptions, and Egyptian/Saudi/Gulf-specific document layouts.

Mostakhles is purpose-built for MENA documents. The module connects your Odoo instance to the Mostakhles AI API and exposes a one-click Extract wizard on any record — invoices, partners, leads, HR contracts, real-estate sales, anything.

What you get

  • One-click "Extract with Mostakhles" button on any Odoo model that you map. Drop an image or PDF, watch the fields populate.
  • 28+ document types auto-detected: tax invoices, Egyptian national IDs, Saudi commercial registers, Arabic prescriptions, lease contracts, passports, bank statements, business cards, utility bills.
  • Cognitive extraction: each result includes a per-field confidence score, plain-language summary, validations (tax-ID checksums, IBAN, MRZ check digits, totals reconcile), and computed values (subtotals, tax, ages).
  • Field mapping wizard: configure how Mostakhles fields land in your Odoo records, save reusable mappings per doctype, share across users.
  • Privacy first: documents are never used to train any AI model — contractually guaranteed via the Mostakhles DPA.
  • Bilingual UI: every label available in Arabic and English; respects user's preferred language.

How it works

  1. Configure the API key — sign up at mostakhles.ai for free credits (30/month, no credit card), paste the key into Settings → Mostakhles.
  2. Click "Extract" — on any Odoo form view, the wizard opens. Drop a document, pick the target doctype (or let auto-detect run), hit Extract.
  3. Review & apply — the wizard shows extracted fields with confidence scores. Edit any low-confidence values inline. Click Apply to write them into the Odoo record.
  4. Audit trail — every extraction is logged on the related record's chatter with the source filename, doctype, and confidence summary.
